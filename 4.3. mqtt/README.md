## Лабораторная работа 4.3. MQTT в FreeRTOS (ESP-idf)
### Цель работы
Требуется написать программу, выполняющую подключение к MQTT серверу, используя Wi-Fi модуль, и получить данные в мониторе порта.

### Ход работы
В качестве заготовки для лабораторной работы код береться из л.р. 3.2, полноценно подключающийся к Wi-Fi.

Также в проект необходимо импортировать библиотеку для работы с mqtt.

Далее меняется программа таким образом, чтобы она могла принимать бесконечное число сообщений из топика и раз в некоторое время публикует некоторое сообщение в него (например время работы программы).
