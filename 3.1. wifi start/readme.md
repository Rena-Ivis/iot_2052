# 3.1 Лабораторная работа: Начинаем работу с Bluetooth-модулем ESP32-S3
## Цель работы
Познакомиться с Bluetooth-модулем чипа ESP32-S3, изучить способы обращения к модулю как к интерфейсу связи посредством работы со встроенными АТ-командами. Получить первоначальные навыки работы с последовательным портом (UART). Получить необходимые навыки работы с платой для ее дальнейшей интеграции с другими модулями и использования в проектах курса "Интернет вещей".
## 3.1.1 Необходимое оборудование
* Плата ESP32-S3-UNO (с чипом ESP32-S3, поддерживающим Bluetooth Classic и BLE)
* Кабель USB Type-C для подключения и питания
* Программа для работы с последовательным портом (Termite, PuTTY, CoolTerm, Arduino IDE Serial Monitor или ESP-IDF)
* Второе Bluetooth-устройство для тестирования (телефон, ноутбук, наушники, другой ESP32)

### План лабораторной работы   

* Выбрать подходящий шаблон для BLE - например gatt-client / gatt-server
* Просканировать сеть и вывести все устройства
* Выбрать конкретное устройство и подклюситься к нему
* После подключения вывести MAC-адрес подключенного устройства

## 3.1.2 Коммуникация через последовательный порт, AT команды
### Что такое GATT Client?

GATT Client - это устройство, которое:
1. Инициирует соединение с BLE-сервером
2. Сканирует доступные BLE-устройства
3. Подключается к выбранному устройству
4. Обнаруживает сервисы и характеристики
5. Читает/записывает данные в характеристики
6. Подписывается на уведомления (notifications)

### Архитектура BLE GATT:
GATT Client (ESP32-S3)  →  Сканирование → Подключение → Обмен данными ← GATT Server (Устройство)
