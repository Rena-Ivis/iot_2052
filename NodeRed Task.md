**Цель работы:** изучить передачу данных по протоколу MQTT, использование библиотеки Paho MQTT и организацию взаимодействия компонентов системы в Node-RED.

   Необходимо реализовать:
   - независимое изменение цветовых каналов RGB (R, G, B);
   - изменение общей яркости;

# Задание 2. Расчётно-графическая работа
### Разработка виртуальной IoT-системы с использованием MQTT, Node-RED и базы данных

**Цель работы:** разработать программный комплекс, моделирующий работу IoT-устройства, взаимодействие с окружающей средой, управление состоянием, передачу и хранение данных.

**Задание**

В соответствии с **выбранным вариантом** необходимо разработать виртуальную IoT-систему, включающую устройство, датчик, модель окружающей среды, мобильное приложение, базу данных и Node-RED.

**1. Разработка программной модели устройства, датчика и окружающей среды**

На языке Python разработать программу, имитирующую работу устройства, датчика и окружающей среды.

Необходимо:
- определить возможные состояния устройства и параметры его работы;
- реализовать изменение состояния устройства в зависимости от поступающих команд;
- предусмотреть моделирование окружающей среды — изменение условий, в которых работает устройство (температуры, влажности, освещённости и т. д.);
- реализовать формирование показаний датчика в зависимости от состояния устройства и условий окружающей среды.

**Важно:** показания датчика должны быть связаны с работой устройства и изменением окружающей среды, а не просто генерироваться случайным образом.

Например, для электрообогревателя необходимо смоделировать температуру помещения. При включении обогревателя температура должна постепенно повышаться, при выключении — снижаться под воздействием окружающей среды. Датчик температуры должен отображать эти изменения.

**2. Разработка системы управления устройством**

Реализовать управление устройством по протоколу MQTT.

Необходимо:
- обеспечить получение управляющих команд;
- реализовать изменение состояния устройства в соответствии с полученными командами;
- разработать алгоритм автоматического управления с использованием обратной связи от датчика.

Для устройств с плавным регулированием параметров необходимо реализовать ПИД-регулятор. Для устройств с дискретными состояниями допускается управление по заданным условиям.

**3. Разработка мобильного приложения**

Разработать мобильное приложение для управления устройством.

Приложение должно:
- отправлять управляющие команды по MQTT;
- позволять изменять доступные параметры работы устройства;
- отображать текущее состояние устройства и показания датчика.

**4. Организация взаимодействия компонентов в Node-RED**

В локально установленной среде Node-RED необходимо:
- настроить получение и отправку MQTT-сообщений;
- реализовать обработку и маршрутизацию данных между компонентами системы;
- организовать передачу показаний датчика в базу данных;
- обеспечить передачу управляющих команд устройству.

**5. Организация хранения данных**

Подключить базу данных для хранения истории показаний датчика.

Необходимо:
- организовать сохранение показаний датчика;
- обеспечить возможность получения ранее сохранённых данных.

**6. Визуализация данных**

В Node-RED разработать панель управления (Dashboard), отображающую:
- текущее состояние устройства;
- актуальные показания датчика.

Дополнительно допускается отображение истории показаний на графиках и использование других элементов визуализации.

**Ожидаемый результат**

Должна быть реализована система, в которой:

1. Пользователь изменяет параметры работы устройства через мобильное приложение.
2. Управляющая команда передаётся по MQTT.
3. Устройство получает команду и изменяет своё состояние.
4. Изменение состояния устройства влияет на моделируемую окружающую среду.
5. Датчик фиксирует изменение соответствующего параметра.
6. Показания передаются через Node-RED и сохраняются в базе данных.
7. Текущее состояние устройства и показания датчика отображаются в панели Node-RED.

**На защиту представить:**
- исходный код программной модели устройства, датчика и окружающей среды;
- реализацию алгоритма управления;
- мобильное приложение;
- схему потоков Node-RED;
- структуру базы данных и примеры сохранённых записей;
- работающую панель управления;
- демонстрацию полного цикла работы системы;
- структурную схему взаимодействия компонентов.
